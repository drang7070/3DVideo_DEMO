3D沉浸式实时语音交互视频

本文档从用户洞察、产品方案、当前架构、AI 原生能力、落地可行性与商业化路径出发，说明项目如何把线性视频升级为可对话、可探索、可评分、可发布的互动叙事体验。

项目概览

荒岛求生 是一款面向沉浸式互动叙事的原型产品。它结合 AI 大模型、三维视差感知、实时语音交互、对话评分机制与可视化创作工具，让用户从“观看故事”转向“参与故事”，也让创作者能够把普通场景和对话场景组织成可发布的体验入口。

产品定位 沉浸式互动视频 + 创作平台
核心体验 三维视差 + 实时语音对话
用户侧入口 介绍页 / 演示页 / 最终页
创作者侧入口 普通编辑器 / 对话编辑器

Participation

从观看到参与

用户不再只能评论或选择固定按钮，而是可以用自然语言表达判断，并让表达进入剧情、评分和场景跳转系统。

Immersion

从画面到空间

通过摄像头识别视角变化，画面可根据头部移动产生视差，让用户主动观察环境细节。

Creation

从作品到工具

创作者可以用低门槛编辑工具搭建互动剧情、配置分支逻辑、管理场景组，并借助 AI 生成内容素材与角色回应。

用户洞察

内容消费正在从“看完一个故事”走向“参与这个故事”。刷弹幕、猜剧情、代入角色、讨论选择，本质上都说明用户希望自己的判断和表达能对内容产生影响。

内容深度用户

Z 世代和年轻职场人长期活跃在 Bilibili、抖音等平台，对互动内容接受度高，也更愿意表达观点。他们在观看解谜、反转、剧情类内容时，常常会主动推理、做判断，甚至替角色做决定。

剧情向轻度玩家

这类用户认可“选择影响剧情”的体验，但传统剧情游戏时间成本高，固定选项也限制了自由表达。他们需要更轻量、更自然的互动方式。

内容创作者

短视频博主、剧情类创作者和品牌内容团队越来越需要形式创新。互动叙事具备传播潜力，但制作门槛高、流程复杂，创作者需要更易用的工具。

用户痛点

被动观看的结构性局限

传统长视频采用线性叙事，用户即使产生判断、情绪或选择冲动，也无法干预剧情发展，只能被动接受结果。在强调参与与体验的内容环境中，这种单向输出逐渐显露不足。

现有互动形式自由度低

评论和弹幕只能增强共鸣，无法影响剧情本身；选择式互动大多依赖固定 A/B/C 选项，预设分支有限，用户体验更像流程解锁，而不是自由参与。

沉浸体验的感官割裂

当前视频仍以二维屏幕为主，视角固定，角色互动单向。VR 或 3D 内容又存在设备门槛、内容供给和自然交互问题，因此需要一种低门槛但高沉浸的中间形态。

创作端技术壁垒高

互动视频要求分支剧情设计、开发能力和三维效果制作，直接导致内容供给不足，也让互动叙事难以进入大众创作场景。

问题的本质是：用户的认知参与没有被转化为叙事变量，创作者的内容想法也缺少低门槛的落地工具。

使用场景

个人沉浸体验

在夜晚或周末的个人娱乐时间，用户打开一条标注为“可参与剧情”的视频。系统通过摄像头完成简单校准，画面呈现荒岛环境，角色开始与用户对话。用户可以直接说出自己的判断，例如优先寻找水源或生火，剧情也会随着表达发生变化。

随着故事推进，用户会通过头部移动观察被遮挡区域、确认线索，逐渐从观看者转变为参与者。系统记录其决策并影响结果，最终形成具有个人行为特征的结局。

社交传播与内容讨论

用户完成一次互动后，可以将自己的结果分享到社交平台。不同用户会因为选择路径不同触发不同走向，甚至发现隐藏情节，讨论重点也从“剧情好不好看”转向“你是如何做出选择的”。

创作者内容升级

创作者可以把原有线性视频改造成互动版本，通过普通编辑器完成场景图层和视差效果，通过对话编辑器配置用户说话场景、实时回复场景、评分区间和结局跳转，使内容从一次性消费转变为可反复体验。

产品方案

产品以“沉浸式互动视频 + 创作平台工具”为核心，将传统线性视频转变为可参与、可对话、可探索、可发布的动态叙事体验。当前版本新增介绍页、普通编辑器、对话编辑器、单场景预览页和最终展示页，前端通过同一套运行时复用渲染、语音、TTS 与场景流转能力。

视觉层

基于摄像头的三维视差系统识别用户眼部位置与视角变化，对画面进行实时调整。用户轻微侧头时，可以看到原本被遮挡的信息，主动发现线索。

交互层

AI 语音对话替代传统选项操作。用户与剧情角色自然交流，系统通过语音识别、大模型意图理解和说服度评分，生成符合角色设定的回应，并按分数区间推动剧情分支。

创作层

创作者通过场景组组织剧情结构，为节点设置 none、auto、dialog、score 等流转模式，并通过图层化方式快速构建三维视差效果。AI 可辅助生成角色设定、对话和分支建议。

产品架构

产品已经升级为单 Node 服务 + 静态前端的轻量架构。服务端集中在 server.js，前端核心逻辑集中在 src/app.js，不同页面通过 body[data-mode] 复用同一套运行时，并通过 index 与 conver 两个数据空间分别管理普通场景和对话场景。

介绍页 intro.html

  • 作为项目总览页，展示作品概念、核心体验、演示视频、移动端 Demo 与创作入口。
  • 通过 intro-demo.html 嵌入轻量体验，适合移动端快速感受 3D 视差。
  • 向非技术观众解释“实时对话、视角探索、多结局”的体验价值。

普通编辑器 index.html

  • 使用 index 数据空间，为创作者提供 Canvas 三维场景编辑器。
  • 支持 PNG、JPG、GIF、MOV、MP4、WebM、音频等素材导入，通过 POST /api/assets 存入本地素材库。
  • 可视化调整图层位置、深度、缩放、旋转、倾斜和透明度，通过 POST /api/layout?space=index 保存。

对话编辑器 index_conver.html

  • 使用 conver 数据空间，专门配置说服、问答、实时回复等对话流程。
  • 支持用户说话场景、实时回复场景、初始分数、评分 Rubric 与分数区间跳转。
  • 可为场景组配置角色人设、用户任务、导演提示词和默认结局。

预览页 viewer.html

  • 用于预览指定场景，可通过 ?scene=、?group=、?space=index|conver 指定来源。
  • 通过 GET /api/layout?id=sceneId 获取场景配置，并用 Canvas 和 DOM 媒体层恢复画面。
  • 适合单独检查场景播放、循环策略、素材层级和视差效果。

最终页 final.html

  • 默认合并 index 与 conver 两个数据空间中允许展示的场景组。
  • 承载完整互动叙事体验，包含摄像头追踪、文字/语音输入、Kimi 角色回应和讯飞 TTS。
  • 支持 ?group=场景组ID 直接进入指定体验入口。

服务层 server.js

  • 提供静态资源、Range 请求、ETag、Gzip、素材上传、场景数据、AI 代理与健康检查。
  • 核心接口包括 /api/layout、/api/settings、/api/director-cue、/api/conversation-cue、/api/tts-stream 和 /health。
  • 当前没有 Vite、Docker 或前端构建步骤，便于本地演示和 PM2 部署。
介绍页导流 → 场景组选择 → 用户语音 / 文字 / 视角输入 → Kimi 意图理解与评分 → 讯飞 TTS 与场景跳转 → 语音、字幕、画面输出

创新差异

本方案的创新不只是技术叠加，而是重新定义视频叙事中用户的位置。用户既可以决定“做什么”，也可以通过视角变化决定“看什么”，还可以通过自然语言和说服度评分影响角色态度与结局走向。

实时与角色对话

产品将传统的选项点击转变为自然语言表达，让用户从被动选择预设路径，转变为主动参与叙事过程。对话编辑器还能把多轮交流、角色人设和评分规则沉淀为可复用的创作配置。

自主决定视角

用户不只影响行动，还可以通过视角变化参与信息获取。隐藏线索、场景细节和空间关系都可以成为叙事变量，并由 Canvas 图层深度和视差参数驱动画面变化。

双编辑器协作

普通编辑器负责场景视觉与基础流转，对话编辑器负责说服、问答、实时回复和分数区间跳转，最终页再合并两个数据空间中允许展示的场景组。

低门槛发布闭环

项目不依赖复杂构建流程，单 Node 服务即可同时提供静态页面、素材上传、场景数据、AI 代理、TTS 代理和健康检查，便于快速演示和部署。

产品不是简单给视频增加互动按钮，而是把视频升级为可以被进入、被探索、被对话、被评分和被持续创作的叙事系统。

AI 原生能力

AI 的核心价值在于把开放语言、用户行为和对话评分转化为剧情变量，让用户从不可干预的观看者变成能影响剧情的参与者，也让创作者用更低成本搭建角色、分支和结局。

使用到的 AI 能力

  • 大模型剧情生成：ChatGPT
  • AI 图像生成：ChatGPT Image 2
  • AI 视频生成：TapNow / Seedance 1.5 / 2.0
  • AI 音乐生成：Minimax Music 2.6
  • 自然语言低代码开发：Codex
  • 自然语言理解、导演提示与说服度评分：Kimi / Moonshot
  • AI 语音合成：讯飞超拟人 TTS，支持一次性返回与流式返回

AI 解决的问题

  • 理解用户自由表达，而不是限制在固定选项。
  • 根据角色人设、剧情状态和对话历史生成实时回复。
  • 将用户语音、情绪倾向、关键指令和说服效果转化为剧情触发条件。
  • 把文本台词合成为符合角色设定的语音音频，并与字幕和画面联动。

系统通过 Moonshot/Kimi API 理解用户语音转写文本，解析剧情决策、对话内容、情绪倾向、关键指令和当前说服度，触发场景跳转或角色交互指令。普通互动走 /api/director-cue，对话评分走 /api/conversation-cue，随后通过讯飞 TTS 的 /api/tts 或 /api/tts-stream 转化为可播放语音，形成用户提问、角色回应、评分更新与场景流转的闭环。

AI 技术方案

创作工作流中的 AI

编剧环节

将主线剧情输入 ChatGPT，由 AI 辅助生成分支剧情、主角人设 Prompt、对话任务、评分 Rubric 与世界观设定，快速搭建多分支叙事框架。

美术与配乐

手绘分镜草图搭配参考图，用 ChatGPT Image 2 生成统一画风的场景和角色素材；使用 TapNow / Seedance 生成视频，使用 Minimax Music 2.6 生成配乐。

开发环节

基于单 Node 服务和原生前端，通过 Codex 自然语言开发完成 Canvas 三维场景编辑器、双数据空间、对话评分流程，并接入 Kimi 与讯飞 TTS 搭建语音交互闭环。

用户核心体验流程

自由探索画面的 3D 效果

摄像头或移动设备姿态采集用户视角数据，实时计算视差参数并驱动 Canvas 场景图层更新；GIF 和视频通过 DOM/Canvas 叠加层保持播放，形成随视角变化的透视效果。

自然语言理解与场景流转

用户语音转写为文本后发送至 Kimi/Moonshot API，AI 解析发言内容，匹配预设剧情逻辑，识别决策、情绪、关键指令和说服度变化。

实时对话生成与语音输出

大模型根据角色人设、对话历史和当前场景生成台词，讯飞 TTS 合成角色音色，浏览器播放音频并同步字幕，完成实时对话闭环。

当前场景流转支持 none、auto、dialog、score 四种模式：既能完成传统自动播放，也能根据关键词和说服度区间进入不同结局。

落地可行性

项目以“先验证体验、再扩展供给”为路线：当前 Demo 已完成单 Node 服务、普通编辑器、对话编辑器、最终展示页、AI 对话代理、TTS 代理和健康检查，具备本地演示与服务器部署的基础。

第一阶段：互动视频 Demo

通过三维视差、语音交互、基础分支逻辑和最终页场景组入口，验证用户是否愿意从观看转向参与。

第二阶段：AI 叙事能力

引入剧情状态管理、对话记忆、说服度评分和多轮上下文理解，使用户行为持续影响叙事走向。

第三阶段：创作平台

继续完善普通编辑器和对话编辑器，让创作者以场景组方式构建剧情结构，并由 AI 承担内容生成、补全和测试。

从技术角度看，项目没有前端构建步骤，依赖 Node.js 原生 HTTP、文件系统、fetch、WebSocket 与浏览器原生能力即可运行。服务端已支持静态资源缓存、Gzip、Range 请求、素材上传、Kimi 代理、讯飞 TTS 代理和 /health 健康检查；线上部署推荐 PM2 + Nginx + HTTPS，以满足摄像头和麦克风的安全上下文要求。

商业化思考

产品的商业价值不只在单个互动视频变现，更在于构建新的内容生产与消费体系。介绍页负责讲清价值、最终页负责吸引用户并验证需求，普通编辑器和对话编辑器负责扩大供给、形成规模。

用户侧付费

互动叙事内容具备更强参与感与沉浸感，可以提升停留时长、重复体验意愿和结局探索欲，为高质量剧情付费、不同结局解锁等模式提供基础。

创作者工具收入

创作平台可以提供高级编辑功能、AI 生成额度、对话评分模板、TTS 音色额度、数据分析服务等稳定收入来源。

品牌内容合作

品牌可以通过定制剧情，把产品或理念融入用户决策路径，让广告从被观看转变为被体验，并获得更细致的用户洞察。

AI 原生叙事平台

随着用户在不同内容中的互动行为积累，选择路径、对话方式和说服结果可以成为个性化数据基础，影响未来内容生成方向。

存量内容改造

除原创互动叙事外，产品还可以对已有影视、短剧、动漫、品牌短片和 IP 内容进行 AI 互动化升级。当前双数据空间和场景组机制，使“原视频空间化 + 新增对话节点 + 多结局发布”成为可复用流程。

低成本空间化重构

通过三维视差技术，原有二维视频可以被重新构建为空间化场景。悬疑内容中用户可主动观察环境，情感内容中用户可更近距离进入角色空间。

可参与剧情升级

AI 语音交互让用户在关键节点与角色实时交流、提出建议，甚至触发不同结局；score 模式还能把对话结果转化为可解释的分数区间。

提升复播与用户洞察

互动化改造可以提升老内容复播率、停留时长与讨论度，同时沉淀用户行为、选择路径和对话数据，用于内容推荐、广告匹配和 IP 开发。

改造效率更高

相比重新制作完整互动游戏，基于原有影视内容的互动化升级成本更低、效率更高，也更符合长视频与短视频平台的内容生产逻辑。

从行业角度看，未来的视频平台可能不再只是内容播放平台，而会逐渐转向内容体验平台。AI 驱动的互动叙事能力，有机会成为下一代内容增长的重要基础设施。
